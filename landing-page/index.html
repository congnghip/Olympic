Giải Quyết Triệt Để Mọi Thách Thức Thực Địa

Xây dựng dựa trên các ràng buộc vận hành thực tế tại đô thị Việt Nam: ngõ hẻm chật hẹp, rào chắn thi công đột xuất và mùi hôi chất thải.

⚡

Tái Định Tuyến Dưới 50ms

Khi phát hiện rào chắn công trình hoặc ngập úng, hệ thống tự động loại bỏ cung đường bị chặn trên đồ thị OSRM và tìm tuyến đường vòng tức thời mà không cần điều phối viên thao tác thủ công.

🔄

San Tải Phương Tiện Hỏng

Khi xe rác gặp sự cố kỹ thuật hỏng hóc giữa ca, hệ thống lập tức trích xuất các bô rác chưa thu gom và tự động san sẻ sang các xe lân cận còn dung tích trống mà không làm vỡ khung giờ thu gom.

🚶

Thu Gom Đi Bộ Hẻm Sâu (Walk-in)

Tự động nhận diện bô rác nằm trong hẻm nhỏ xe cơ giới không vào được. Hệ thống vạch điểm đỗ thích hợp ở đầu hẻm và hướng dẫn công nhân đi bộ vào lấy thùng rác, khắc phục hạn chế của bản đồ thông thường.

👃

Ưu Tiên Rác Bốc Mùi

Thuật toán Clarke-Wright tích hợp hệ số thưởng (Urgency Bonus) cho các thùng rác bốc mùi (has_smell=true), đảm bảo các điểm nóng ô nhiễm được giải phóng trước tiên.

⚖️

Bản Đồ Kép Đối Chứng (Dual-Map)

Hỗ trợ hiển thị song song hai màn hình để đối chiếu giải thuật đề xuất với giải thuật Baseline truyền thống, cung cấp bằng chứng định lượng rõ ràng về hiệu quả cắt giảm chi phí và thời gian.

🌿

Đo Lường Phát Thải ESG

Tự động tính toán lượng khí thải $\text{CO}_2$ cắt giảm dựa trên định mức nhiên liệu thực tế ($0.285 \text{ kg CO}_2/\text{km}$), hỗ trợ trực tiếp công tác báo cáo phát triển bền vững của doanh nghiệp môi trường.

Mô hình phân tầng

Kiến Trúc Kỹ Thuật Độc Lập

Phân tách rõ ràng giữa giao diện WebGIS tương tác, dịch vụ API Gateway, và lõi giải thuật C++17 song song.

Presentation Layer Port 8502 & 8501

Giao Diện Điều Phối & Phân Tích

  • ✓ WebGIS IOC (Port 8502): Giao diện Leaflet bản đồ kép, mô phỏng rào chắn, âm thanh cảnh báo.
  • ✓ Streamlit Dashboard (Port 8501): Phân tích độ nhạy thuật toán, tinh chỉnh siêu tham số $\alpha, \beta, \rho$.
  • ✓ Bản đồ vệ tinh: OpenStreetMap & ArcGIS World Imagery (100% không đường 9 đoạn).
Services Layer Port 8000 & 8502

Dịch Vụ API Backend

  • ✓ FastAPI Map Server (8502): Cung cấp REST endpoints cho kịch bản rác, sự cố và báo cáo tài xế.
  • ✓ Core Solver API (8000): Cổng giải bài toán VRP định dạng chuẩn Solomon qua C++ wrapper.
  • ✓ Incident Dispatcher: Quản lý hàng đợi sự kiện và tự động san sẻ tải phương tiện.
Algorithms & Data C++17 & Cache

Động Cơ Giải Thuật Lõi

  • ✓ 3D-Parallel ACO (C++17): Giải thuật đàn kiến đa luồng OpenMP hiệu năng cao.
  • ✓ Clarke-Wright & OR-Tools: Tối ưu hóa tải trọng và so sánh đối chứng đa tiêu chí.
  • ✓ OSRM Route Cache: Ma trận khoảng cách đường phố TP.HCM giúp truy xuất tức thì.

Triển Khai Bằng 1 Lệnh Duy Nhất

Toàn bộ môi trường C++17, Python 3.11, FastAPI và Streamlit đã được cấu hình trọn gói trong Docker Compose.

bash terminal 
# 1. Clone repository từ GitHub
git clone git@github.com:congnghip/Olympic.git
cd Olympic

# 2. Khởi chạy toàn bộ hệ thống bằng Docker Compose
docker compose up -d --build

# 3. Truy cập trung tâm điều phối WebGIS
open http://localhost:8502
